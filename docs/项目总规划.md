# Agent Platform — 项目总规划

## 一、项目定位

在现有 `agent_platform`（Function Calling + ReAct + 工具注册）基础上，扩展为一个**轻量级 LLM 应用开发平台**，类似 Dify 但更轻量、更适合个人/小团队使用。

### 核心差异（vs Dify）

| 维度 | Dify | 我们的方案 |
|------|------|-----------|
| 部署 | Docker Compose (PostgreSQL+Redis+Worker) | **单进程** (SQLite，零依赖) |
| 前端 | Next.js + ReactFlow (需Node构建) | **Vue3 CDN** (单HTML，无需构建) |
| 工作流 | 15种节点，复杂但重 | **6种核心节点**，够用且轻 |
| RAG | 30+向量数据库 | **SQLite + TF-IDF** 内置向量化 |
| 适合 | 企业级多租户 | **个人/小团队**，一台服务器搞定 |

## 二、功能模块总览

### ✅ 模块1：应用管理（AppManager）— 已完成

- [x] 创建/编辑/删除应用
- [x] 应用类型：聊天助手、工作流
- [x] 每个应用独立配置：系统提示词、模型、工具、知识库
- [x] 应用对话（流式 SSE + RAG 知识库检索）

### ✅ 模块2：工作流引擎（WorkflowEngine）— 已完成

- [x] DAG 拓扑排序执行引擎
- [x] 变量插值系统（`{{node_id.field}}` 语法）
- [x] 6 种核心节点：
  1. **LLM** — 调用大模型，支持 Prompt 模板
  2. **知识检索** — 从知识库检索相关内容
  3. **代码执行** — 安全沙箱运行 Python 代码
  4. **条件分支** — IF/ELSE 判断（10 种操作符）
  5. **HTTP 请求** — 调用外部 API
  6. **工具** — 调用已注册的工具
- [x] 工作流运行记录和日志
- [ ] 可视化拖拽式 DAG 画布（前端）

### ✅ 模块3：知识库（RAG）— 已完成

- [x] 文档上传（TXT/MD 等纯文本）

- [x] TF-IDF 向量化（中英文混合分词）
- [x] 语义检索（余弦相似度，跨数据集搜索）
- [x] 知识库管理（增删改查）
- [x] 关联到应用（RAG 增强对话）
